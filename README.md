# Sri Kaleeswarar S — Academic Portfolio

Single-file site (index.html). No build step.

## Edit
Open index.html and find the block "EDIT HERE":
- SITE: name, intro, photo, github, email, calendly link, default palette
- PALETTES: add or change colour rows
- PAGES: add a page by adding one object; blocks are stats | cards | text | table | gallery | calendly

## Photos
Put images in /images and reference them, e.g. "images/me.jpg".

## Calendly
Set SITE.calendly = "https://calendly.com/your-name/30min"

## Publish on GitHub Pages
1. Create a repo (e.g. yourname.github.io) and upload these files.
2. Settings -> Pages -> Deploy from branch -> main / root.
